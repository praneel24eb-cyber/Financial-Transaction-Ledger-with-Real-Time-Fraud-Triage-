Indexing Optimization
Ledger Scan Index

Index on LEDGER_ENTRY(account_id, created_at) reduces account history retrieval from Seq Scan (14.2 ms) to Index Scan (0.8 ms) — a 17.75× speedup.

Velocity Transaction Index

Index on TRANSACTION(initiated_at) accelerates the rolling 30-day aggregate feature calculations powering real-time Isolation Forest fraud triage.

Partitioning & Redis Caching
Monthly RANGE Partitioning

LEDGER_ENTRY is partitioned monthly by created_at. The query planner automatically prunes historical partitions during active-month queries.

Redis INCR vs SQL Aggregate

Redis INCR velocity lookup: ~0.4 ms vs PostgreSQL SQL aggregate: ~3.1 ms — 7.75× faster on hot-path fraud scoring.
